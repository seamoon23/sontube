# SonTube Android Parent Authentication Design

Updated: 2026-08-24

## 목적

이미 앱 키가 등록된 아이 기기에서 설정 열기와 앱 키 교체를 보호한다. 영상 선택과 재생에는 인증을 요구하지 않는다. 이 기능은 화면 고정을 보완하지만 Android 기기 관리자나 완전한 키오스크를 대신하지 않는다.

## 결정

1. 설치형 Android 앱은 운영체제의 기기 자격 증명(PIN, 패턴 또는 비밀번호)을 첫 번째 방식으로 사용한다.
2. 현재 웹 화면의 산수 문제는 일반 브라우저 QA와 초기 개발용 보조 장치일 뿐, 보안 인증으로 간주하지 않는다.
3. 앱 키가 없는 최초 설정은 지금처럼 바로 열 수 있다. 유효한 키가 한 번 등록된 뒤에는 설정 열기와 교체 키 입력 전에 매번 부모 인증을 요구한다.
4. 인증 성공은 한 번의 설정 진입에만 사용한다. 시간 기반 장기 잠금 해제 상태나 재사용 가능한 인증 토큰은 저장하지 않는다.
5. 기기에 PIN·패턴·비밀번호가 없으면 등록된 키의 변경 화면을 열지 않고 부모에게 Android 화면 잠금 설정을 안내한다.
6. 별도 SonTube PIN은 1차 구현에 넣지 않는다. 운영체제 인증을 사용할 수 없는 기기를 실제 사용자가 요구할 때만 안전한 저장·재시도 제한·복구 절차와 함께 별도 설계한다.

## 위협 범위

막으려는 대상:

- 아이가 흐린 설정 버튼을 우연히 누르고 앱 키를 바꾸는 경우
- 단순 반복 입력으로 설정 화면을 여는 경우
- 앱을 잠시 벗어나 다시 돌아왔을 때 이전 인증 상태가 남는 경우

1차 구현이 막지 못하는 대상:

- 루팅된 기기, 변조된 APK 또는 디버그 가능한 별도 빌드
- 보호자의 Android 잠금 자격 증명을 이미 아는 사용자
- Device Owner/DPC 없이 Home·최근 앱까지 완전히 통제하는 요구

## 구현 경계

Android 네이티브가 시스템 인증 화면을 시작하고 결과를 WebView에 일회성으로 전달한다. WebView는 성공 결과를 받은 현재 요청에서만 설정을 연다.

- 네이티브: `MainActivity`의 `SonTubeDevice` bridge에 비동기 인증 요청 추가
- 웹: `components/app/app-shell.tsx`에서 네이티브 bridge가 있으면 산수 문제 대신 시스템 인증 요청
- 생명주기: 앱이 background로 이동하거나 네트워크 fail-closed 화면으로 전환되면 진행 중 인증과 잠금 해제 상태 폐기
- release: WebView 디버깅은 계속 비활성 상태 유지

UI gate만으로는 개발자 콘솔 수준의 변조를 완전히 막지 못한다. 공개 배포 전 후속 단계에서는 원문 앱 키를 WebView `localStorage`에서 Android Keystore로 보호되는 네이티브 저장소로 옮기고, 키 교체 커밋도 네이티브 인증 상태와 결합한다.

## 실패와 복구

- 인증 취소·실패: 설정을 열지 않고 아이 카탈로그로 돌아간다.
- Activity 재생성·앱 background: 인증 성공 상태를 복원하지 않는다.
- 화면 잠금 미설정: Android의 `설정 > 보안 또는 보안 및 개인정보 보호 > 화면 잠금` 경로를 안내한다.
- 기존 앱 키 분실: 기기에서 우회하지 않고 부모 관리자 `관리자 화면 > 앱 키`에서 새 키를 만든 뒤 인증된 교체 흐름을 사용한다.

## 실기기 QA

- PIN, 패턴 또는 비밀번호가 설정된 기기에서 성공·취소·실패를 각각 확인한다.
- 생체 인식이 설정된 제조사 기기에서도 최종 기기 자격 증명 fallback이 가능한지 확인한다.
- 인증 중 Home, 회전, 화면 잠금과 앱 복귀 후 설정이 열리지 않는지 확인한다.
- 앱 고정 상태에서 시스템 인증 화면이 허용되는지 제조사별로 확인한다.
- 등록된 키 교체 실패 시 기존 키와 승인 카탈로그가 그대로 보존되는지 다시 확인한다.

## 별도 SonTube PIN을 나중에 추가한다면

- 평문·단순 해시 저장 금지
- 기기별 salt와 느린 KDF 사용
- Android Keystore로 검증 데이터 보호
- 실패 횟수 제한과 지수형 대기
- 부모 관리자에서 새 앱 키를 통한 명시적 재설정 절차
- 로그와 오류 문구에 PIN 또는 앱 키 원문 미기록
