# SonTube Android Client

## 제품 구분

- 부모는 PC 또는 모바일 브라우저의 `/admin`에서 영상, 태그, 추천 여부와 앱 키를 관리합니다.
- 아이는 일반 브라우저가 아니라 `android-client/`로 만든 설치형 Android 앱을 사용합니다.
- 앱은 서버의 `/app`만 보여주며 주소창, 전체 검색, 관리자 메뉴와 외부 사이트 이동을 제공하지 않습니다.

## 구현 상태

- 관리자 앱 키 생성, 14일 체험 상태와 설치 ID 최초 바인딩
- 승인된 내부 카탈로그 JSON만 `/api/app/register`, `/api/app/sync`로 전달
- 키 등록 전 영상 미노출, 시작·복귀마다 버전 확인, 변경된 경우에만 목록 수신
- 제목, 보호자 검색어와 태그를 대상으로 하는 로컬 검색(관리자 설명은 검색에서 제외)
- 부모 최근 추천, 핫태그, 아이 재생목록과 영상 피드백
- 최상위 WebView URL을 정확한 scheme, host, port와 `/app` 경로로 제한
- `/admin`, `/kids`, 외부 YouTube 페이지, 검색 사이트, custom scheme와 사용자 정보 URL 차단
- 새 창, 다운로드, 파일 접근, 앱 권한 요청 차단
- WebView 탐색 기록 미복원, 뒤로가기 목적지와 History API 주소 재검사
- YouTube iframe 전체 화면 지원, 종료 시 같은 영상 반복 재생
- debug 로컬 HTTP 허용, release HTTPS `/app` 주소 빌드 검증
- 공식 Gradle Wrapper 포함
- 부모 Wi-Fi 필수 정책 선확인과 실패 시 로컬 샘플 화면
- 새 키 정상 승인 뒤에만 기존 키와 목록 교체

## 보안 경계

WebView 제한은 앱 안에서 임의 외부 사이트로 이동하는 것을 막습니다. 일반 Android 앱만으로 기기의 홈 버튼과 다른 앱 실행까지 완전히 막을 수는 없습니다.

아이 기기에서는 `설정 > 보안 또는 보안 및 개인정보 보호 > 기타 보안 설정 > 앱 고정`에서 화면 고정을 함께 사용합니다. 제조사에 따라 메뉴 이름은 다를 수 있습니다. 완전한 키오스크는 기기 소유자 또는 DPC가 앱을 허용 목록에 넣은 Lock Task 구성이 필요합니다.

YouTube iframe은 SonTube 외부에서 동작하는 플레이어입니다. 동일 영상 반복과 sandbox로 종료 추천 및 최상위 이동을 줄이지만 YouTube 자체 광고, 플레이어 요소와 내부 동작을 완전히 제거하거나 변조하지 않습니다. 엄격한 승인 영상 전용 보장을 제품 핵심 조건으로 확정한다면 YouTube iframe의 정책 한계를 별도 검증해야 합니다.

## 실제 기기 검증

1. Android Studio에서 `C:\codex\app\sontube\android-client`를 엽니다.
2. 실제 기기 또는 에뮬레이터에서 앱 키를 등록합니다.
3. 앱 시작과 전면 복귀마다 버전을 확인하고, 목록이 바뀐 경우에만 새 승인 목록을 받는지 확인합니다.
4. YouTube 로고, 제목, 공유 요소와 새 창 링크를 눌러도 최상위 외부 페이지가 열리지 않는지 확인합니다.
5. 전체 화면 진입과 종료 뒤 재생 화면이 정상 복구되는지 확인합니다.
6. Wi-Fi 필수/전체 허용 각각에서 앱 재시작, 네트워크 단절, 로컬 샘플 화면과 서버 복구를 확인합니다.
7. 화면 고정을 켜고 홈, 최근 앱, 뒤로가기 동작을 기기 제조사별로 확인합니다.

## 후속 범위

- 두 종류 이상의 실제 Android 기기에서 재생, 전체 화면, 화면 고정과 외부 이동 차단 검증
- 부모 PIN 또는 Android 기기 인증으로 앱 설정 보호 강화
- 엄격한 승인 영상 경계를 위한 YouTube iframe 내부 전환 감시 가능성 검증
- 관리형 전용 태블릿이 필요할 때 DPC/Device Owner Lock Task 적용
- Play Store 서명, 아이콘, 개인정보 처리방침과 웹 결제 정책 검토
- iOS 제한형 클라이언트 타당성 검토
